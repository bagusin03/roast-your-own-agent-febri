The Phantom Tool Call: a one-line roast of my own AI agent for the make.fun "Roast Your Own Agent" bounty. `main.ts` writes a single 120-character roast to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> My agent never ran the tool, hallucinated its output, apologized for the delay, then thanked itself for a job well done.

## Run it

```sh
node main.ts
```
